# Tangent grid

`scripts/roll` samples unique domain prompts from this file. Each prompt exists
only to widen the candidate pool beyond the model's habits. It never determines
the final topic, format, source, constraint, or opening. Edit the list to change
the available nudges, keeping every entry on one line.
