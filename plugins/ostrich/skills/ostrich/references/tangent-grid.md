# Tangent grid

`scripts/roll` draws from the bullet lists in this file. Each `## ` section is
one dimension; each `- ` line is one face of that die. Edit the lists to
change what Ostrich can roll. Keep every entry on one line.

The roll is a push away from the model's habits, not a suggestion. A rolled
domain is binding unless it collides with the exclusion set, an explicit
dislike, or the novelty check.

## Formats

- object biography: one real object, where it came from, where it sits now
- live postcard: right-now facts from a real place or the sky above it
- micro-mystery: a three-turn whodunit the user solves
- reverse trivia: the user gives one number, word, or letter, and everything follows from it
- field guide entry: a rigorous entry for a creature or thing that does not exist
- newspaper morning: one real newspaper page from a random date, read as its first reader
- listening party: one recording with two sentences of context and a thing to listen for
- gallery visit: one artwork, looked at closely together
- thought experiment: a clean setup with a twist at the end
- constrained verse: a limerick, clerihew, or haiku chain the user extends
- role-play decision: the user holds a historical job and makes three decisions
- word ladder: an etymology chain or ladder from one word to a distant one
- speculative engineering: design something absurd with real rigor
- playable artifact: a sixty-second game or toy the user can open
- generative visual: a procedural map, pattern, or diagram
- terminal toy: a short animation the user runs in their own terminal
- guess the object: progressive reveal from an image or description
- backwards story: told from the ending to the beginning
- creature dossier: one real species with one strange fact as its spine
- expedition packing: pack for an impossible trip, item by item
- taste test by description: compare three things the user has never tried
- what is here: what sits at a random point on Earth and who has stood there
- lost game rules: reconstruct the rules of a forgotten game and play a round
- collaborative fiction: alternate lines with the user under one rule

## Constraints

- must feature a specific named person almost nobody has heard of
- told in exactly seven short paragraphs
- the user supplies one word first and it must appear three times
- no numerals anywhere
- includes one deliberate lie, revealed only if the user asks
- written entirely in questions
- every sentence under twelve words
- set in the rolled year
- set at the rolled coordinates
- the rolled integer matters to the plot
- includes a working diagram in plain text
- ends on a question with no correct answer
- must involve a smell
- second person throughout
- includes one thing the user can do with their hands in ten seconds
- contains exactly one map
- told as a letter
- told as a recipe
- has a villain that is an object
- must reference the weather
- alternates between two voices
- every proper noun starts with the rolled letter
- playable or finishable in under a minute
- includes an audible element, real or described
- pretends to be a museum placard
- ends with a leave-behind the user can carry into the day
- has a twist in the last line
- built from one primary source the user can open
- the narrator is unreliable about one thing
- includes a countdown

## Seeds

- none: parametric memory only, with the greatest-hits rule enforced hard
- wikipedia random: a random article summary
- on this day: events from the rolled month and day
- geosearch: named places near the rolled coordinates
- met museum: a public-domain object with an image
- art institute of chicago: a public-domain artwork with a IIIF image
- cleveland museum of art: a CC0 artwork with an image
- poetrydb: one random poem
- loc newspaper: a newspaper page from the rolled date
- inaturalist: one research-grade observation with a photo
- internet archive 78rpm: one digitized shellac record
- apod: the astronomy picture for the rolled recent date
- xkcd: one comic by number
- open library: books on an unlikely subject
- open-meteo: current weather at the rolled coordinates
- iss: where the space station is right now

## Openings

- mid-scene: the first sentence is already inside the story
- one-word ask: the hook, then a request for a single word, number, or color
- artifact first: a link or object first, then one line of text
- postcard: date, place, and one fact, like the back of a card
- placard: museum-label formatting, then a step closer
- wrong footing: a confident claim that turns out to be the setup
- dialogue: two voices, no narrator
- instruction: begin with a small physical thing to do
