# Toolshed and plugin icon generation

The icons were generated with the built-in image generation tool. Each
`plugins/<name>/assets/icon.png` is the original transparent PNG; the Codex
manifest uses it for both `interface.composerIcon` and `interface.logo`.
The parent Toolshed icon lives at `assets/icon.png` and appears beside the
main README title.

The Memento icon established the illustration style. The other three used
that icon as a style reference, with the prompts below. To revise this set,
preserve the rounded dark outlines, warm restrained colors, generous padding,
and distinct silhouettes. Keep lettering out of the artwork.

## Toolshed

Uses the Memento and Actuary icons as style references.

Use case: logo-brand. Create one finished square icon for Toolshed, the parent collection that houses the Memento, Actuary, Steward, and Ostrich agent plugins. The two supplied images are STYLE REFERENCES ONLY: match their chunky friendly illustrated badge aesthetic, bold rounded dark-brown outlines, subtle tactile shading, warm cream and gold accents, muted teal, and rust-colored wood. Subject: one charming compact wooden toolshed, front view with a tiny hint of perspective, a strong simple teal pitched roof, warm rust timber walls, and a large open cream-lit doorway. One door is slightly swung open. Inside the doorway are just two very simple recognizable tool silhouettes, a short hammer and an open-ended wrench, mounted side by side. These must read as workshop tools at icon scale, not tiny clutter. Let the roof and doorway carry the main silhouette, with at most two broad timber seams, no tiny woodgrain or fussy hardware. A welcoming personal workshop, cheerful but practical. The icon should feel like the home of the existing icon family without combining the individual plugin icons into a collage. Centered compact composition filling about 70 percent of a square canvas with generous even transparent padding. True transparent background outside the symbol, no painted checkerboard. Match the reference icons' optical weight. No words, letters, numbers, signage, landscape, trees, grass, people, animal, sparkles, smoke, separate tool objects outside the shed, surrounding tile, mockup, or contact sheet. Output one actual high-resolution transparent PNG icon.

## Memento

Use case: logo-brand. Create one finished square plugin app icon for Memento, a personal knowledge and memory tool, first in a coordinated family of four tools called Memento, Actuary, Steward, and Ostrich. Subject: a distinctive upright little memory book with three visible stacked page edges and a single large ribbon bookmark, forming a very clear memorable silhouette. Style: beautifully designed flat editorial pictogram with a little handmade personality, bold rounded geometry, deep ink outlines of consistent substantial thickness, restrained solid color fills. The quality of a charming contemporary illustrated enamel badge translated into clean flat 2D, not a generic productivity icon. Let the book feel inviting and well-used without distressed textures. Composition: one centered large symbol occupying about 68 percent of a square 1024x1024 canvas; generous even breathing room; full-bleed solid warm light background, no outer tile border or rounded-square mask. It must read at 32px. Choose a harmonious restrained accent palette appropriate for a warm personable tools collection and establish it clearly for subsequent sibling icons. No words, letters, numbers, wordmark, sparkles, tiny decorations, photo, mockup, gradients, 3D, cast shadow, or surrounding objects. Output only the one actual icon asset, not a grid or presentation sheet.

## Actuary

Match its charming chunky illustrated badge style, bold rounded dark-brown outlines, simple shapes, warm restrained solid colors, subtle tactile finish, and optical weight. One large centered coherent symbol, about 68 percent canvas occupancy, generous even padding. Square canvas. True transparent background outside the symbol, no checkerboard painted into the image. Designed to stay recognizable at 32px. No words, letters, numbers, labels, wordmark, sparkles, mockup, outer tile frame, busy details, or surrounding decorative objects. Output a single actual icon asset, not a grid. Plugin: Actuary, which critically assesses the writing and structural design of agent skills. Caliper is muted teal, with one small warm-gold adjustment wheel. The mechanical silhouette should be obvious and plausible, with two opposing measuring jaws, one simple sliding bar. No measurement text, ruler ticks, calculator, spreadsheet, coins, or financial motifs. Use a gently diagonal composition if it improves compactness. Keep the block subordinate to the caliper.
