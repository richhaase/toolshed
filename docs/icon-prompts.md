# Toolshed and plugin icon generation

The icons were generated with the built-in image generation tool. Each
`plugins/<name>/assets/icon.png` is the original transparent PNG; the Codex
manifest uses it for both `interface.composerIcon` and `interface.logo`.
The parent Toolshed icon lives at `assets/icon.png` and appears beside the
main README title.

The Memento icon established the illustration style. The other plugin icons used
that icon as a style reference, with the prompts below. To revise this set,
preserve the rounded dark outlines, warm restrained colors, generous padding,
and distinct silhouettes. Keep lettering out of the artwork.

## Toolshed

Uses the Memento and Actuary icons as style references.

Use case: logo-brand. Create one finished square icon for Toolshed, the parent collection that houses the Memento, Actuary, and Ostrich agent plugins. The two supplied images are STYLE REFERENCES ONLY: match their chunky friendly illustrated badge aesthetic, bold rounded dark-brown outlines, subtle tactile shading, warm cream and gold accents, muted teal, and rust-colored wood. Subject: one charming compact wooden toolshed, front view with a tiny hint of perspective, a strong simple teal pitched roof, warm rust timber walls, and a large open cream-lit doorway. One door is slightly swung open. Inside the doorway are just two very simple recognizable tool silhouettes, a short hammer and an open-ended wrench, mounted side by side. These must read as workshop tools at icon scale, not tiny clutter. Let the roof and doorway carry the main silhouette, with at most two broad timber seams, no tiny woodgrain or fussy hardware. A welcoming personal workshop, cheerful but practical. The icon should feel like the home of the existing icon family without combining the individual plugin icons into a collage. Centered compact composition filling about 70 percent of a square canvas with generous even transparent padding. True transparent background outside the symbol, no painted checkerboard. Match the reference icons' optical weight. No words, letters, numbers, signage, landscape, trees, grass, people, animal, sparkles, smoke, separate tool objects outside the shed, surrounding tile, mockup, or contact sheet. Output one actual high-resolution transparent PNG icon.

## Memento

Use case: logo-brand. Create one finished square plugin app icon for Memento, a personal knowledge and memory tool, first in a coordinated family of three tools called Memento, Actuary, and Ostrich. Subject: a distinctive upright little memory book with three visible stacked page edges and a single large ribbon bookmark, forming a very clear memorable silhouette. Style: beautifully designed flat editorial pictogram with a little handmade personality, bold rounded geometry, deep ink outlines of consistent substantial thickness, restrained solid color fills. The quality of a charming contemporary illustrated enamel badge translated into clean flat 2D, not a generic productivity icon. Let the book feel inviting and well-used without distressed textures. Composition: one centered large symbol occupying about 68 percent of a square 1024x1024 canvas; generous even breathing room; full-bleed solid warm light background, no outer tile border or rounded-square mask. It must read at 32px. Choose a harmonious restrained accent palette appropriate for a warm personable tools collection and establish it clearly for subsequent sibling icons. No words, letters, numbers, wordmark, sparkles, tiny decorations, photo, mockup, gradients, 3D, cast shadow, or surrounding objects. Output only the one actual icon asset, not a grid or presentation sheet.

## Actuary

Use case: logo-brand. Generate one finished square plugin icon, a sibling of the supplied Memento book icon. The supplied image is STYLE REFERENCE ONLY, not a subject to copy. Match its charming chunky illustrated badge style, bold rounded dark-brown outlines, simple shapes, warm restrained solid colors, subtle tactile finish, and optical weight. One large centered coherent symbol, about 68 percent canvas occupancy, generous even padding. Square canvas. True transparent background outside the symbol, no checkerboard painted into the image. Designed to stay recognizable at 32px. No words, letters, numbers, labels, wordmark, sparkles, mockup, outer tile frame, busy details, or surrounding decorative objects. Output a single actual icon asset, not a grid. Plugin: Actuary, which critically assesses the writing and structural design of agent skills. Subject: one friendly precision caliper with substantial simple jaws holding a small square cream-colored block snugly between them, a clear visual metaphor for measuring design quality. Caliper is muted teal, with one small warm-gold adjustment wheel. The mechanical silhouette should be obvious and plausible, with two opposing measuring jaws, one simple sliding bar. No measurement text, ruler ticks, calculator, spreadsheet, coins, or financial motifs. Use a gently diagonal composition if it improves compactness. Keep the block subordinate to the caliper.

## BigBoard

Uses the Memento and Actuary icons as style references. The selected concept is
an activity easel.

Use case: logo-brand / style-transfer. Create one BigBoard plugin icon by replacing the subject of the supplied reference icons while matching their established Toolshed illustration style. The two input images are STYLE REFERENCES ONLY, not subjects to combine. Match their chunky friendly illustrated enamel-badge character, thick consistent rounded dark-brown outlines, restrained warm cream and gold, muted teal, rust-colored wood, subtle tactile shading, optical weight, and slightly handmade rounded geometry. This is a sibling in the same icon family, not a new branding style.
Asset type: square plugin icon, one centered coherent physical object, filling about 68–72 percent of the canvas with generous even transparent padding. Keep the complete silhouette inside the canvas. The final icon must stay recognizable at 32 pixels. True transparent alpha background outside the symbol; no black, white, colored, or checkerboard background painted behind it. No enclosing app tile, border around the canvas, glow, cast shadow, photorealism, shiny 3D, scenery, people, words, letters, numbers, labels, watermark, decorative sparkles, tiny UI elements, or presentation sheet. Output one actual high-resolution transparent icon asset only.
Subject: one compact freestanding briefing board on a sturdy simple rust-wood easel. A broad landscape warm-cream board face in a substantial muted-teal rounded frame, with just three large simple rising activity bars: teal, warm gold, and rust. Use strong simple bar silhouettes and no axes or gridlines. The rust-wood easel has two clear visible legs and a short central upright behind the board, mechanically plausible, no extra objects. One small gold joint or knob is sufficient. Near front view with a tiny hint of perspective. The board itself should dominate, while the easel gives a distinct workshop-object silhouette. Communicate a big visual overview of repository activity.
